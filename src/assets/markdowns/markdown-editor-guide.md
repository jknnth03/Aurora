## Features

-   **Live Preview**: See your markdown rendered in real-time
-   **Download**: Save your work as a .md file
-   **Split View**: Edit and preview side by side
-   **Formatting Toolbar**: Use buttons to format text quickly

## Getting Started

Start typing in the editor on the left to see the preview update automatically.

### Supported Markdown Elements

-   Headers (# ## ###)
-   **Bold** and _italic_ text
-   [Links](https://example.com)
-   Lists and numbered lists
-   `inline code` and code blocks
-   > Blockquotes
-   Tables

### Example Commit Messages

```bash

git commit -m "🐛 Fix login button alignment on mobile"
git commit -m "📝 Update API documentation for v2.0"
git commit -m "⚡ Optimize database queries for faster loading"
git commit -m "🔥 Remove deprecated payment methods"
git commit -m "🚑 Fix critical security vulnerability in auth"
```

### Usage Tips

1. **Keep it simple**: Use one primary gitmoji per commit
2. **Be descriptive**: Follow the emoji with a clear, concise message
3. **Stay consistent**: Pick a style and stick with it across your project
4. **Reference issues**: Include issue numbers when relevant
5. **Use present tense**: "Add feature" not "Added feature"
